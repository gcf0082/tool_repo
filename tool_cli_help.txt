tool_cli — client wrapper for tool_repo

Commands:
  set-url <url>                     Save server URL to ~/.tool_cli/config.json
  config                            Show current config
  url                               Print the configured URL
  ping                              Check connectivity to the configured server
  get <name> [options]              Download a package into the current dir
    options:
      --version, -v <v>             Exact version (default: latest)
      --os <os>                     Override os (default: detected via uname)
      --arch <arch>                 Override arch (default: detected via uname)
      --dir, -d <path>              Target directory (default: current dir)
  install <name> [options]          Download + extract archive into target dir
    options:
      --dir, -d <path>              Install directory (default: /usr/local/bin)
      --version, -v <v>             Exact version (default: latest)
  run remote://<path> [args...]     Execute a remote shell script via pipe
                                    (args are passed to the script's "$@")
  push <local> remote://<path>      Upload a local file to scripts/<path>
  help                              Show this message (always fetched from the
                                    server so it stays up to date)

Environment:
  TOOL_CLI_URL=<url>                Override the configured URL for one call

Help source:
  This text is served by the tool_repo at GET /tool_cli_help and is
  bundled with the server binary — whenever the server is upgraded,
  every 'tool_cli help' call reflects the new subcommands without
  needing to reinstall tool_cli.
